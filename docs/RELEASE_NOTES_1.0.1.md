# Passphrase Memorizer 1.0.1

English | Deutsch below

The app remembers the last selected local GGUF model path and reconnects it automatically at startup after repeating the local-file checks. Choose Gemma 4 E4B or another supported local model once at its installed location. Missing, moved, cloud-hosted, network-hosted or symbolic-link files remain unavailable. Restore a valid local file at the original location for a later launch, or choose another valid local file. No replacement is downloaded.

The retained preferences are language, window width, window height and model path. Passphrases, prompts, generated text and conversations remain volatile. Clear and orderly quit remove session state while retaining these setup preferences. The fresh isolated worker's network and write restrictions are unchanged. The GUI displays version 1.0.1; the ten-minute reveal and literal blue, bold `[word]` markers remain unchanged.

This update is distributed with SHA-256, SHA3-512 and Skein-1024-1024 values, both RSA-4096-PSS/SHA-512 and ML-DSA-87 for all four release targets, and Apple Developer ID/notarization. The independently notarized Hybrid Signer remains version 1.0.0 and its archive is unchanged. Model weights are excluded from Git and releases. Follow the [model guide](LOCAL_AI.md), [hybrid verification guide](HYBRID_SIGNING.md) and [internal audit](SECURITY_AUDIT.md).

## Deutsch

Die App merkt sich den zuletzt gewählten lokalen GGUF-Modellpfad und bindet ihn beim Start nach erneuter Prüfung automatisch an. Wähle Gemma 4 E4B oder ein anderes unterstütztes lokales Modell einmal an seinem Installationsort aus. Fehlende, verschobene Dateien, Cloud- oder Netzwerkdateien und Symlinks bleiben gesperrt. Stelle für einen späteren Start eine gültige lokale Datei am ursprünglichen Ort wieder her oder wähle ein anderes gültiges Modell. Es wird kein Ersatz heruntergeladen.

Gespeichert werden Sprache, Fensterbreite, Fensterhöhe und Modellpfad. Passphrase, Prompt, generierte Texte und Chatverlauf bleiben flüchtig. Leeren und reguläres Beenden löschen die Sitzung und behalten die Einrichtungseinstellungen. Netzwerk- und Schreibverbote des jeweils frischen isolierten KI-Prozesses bleiben unverändert. Die Oberfläche zeigt Version 1.0.1. Die zehnminütige Anzeige und wörtliche blaue, fette `[Wort]`-Markierungen bleiben erhalten.

Die Veröffentlichung enthält SHA-256-, SHA3-512- und Skein-1024-1024-Werte, RSA-4096-PSS/SHA-512 und ML-DSA-87 für alle vier Release-Ziele sowie Apples Developer-ID-Signatur und Notarisierung. Der separat notarisierte Hybrid Signer bleibt Version 1.0.0; sein Archiv bleibt unverändert. Modellgewichte fehlen in Git und Releases. Details stehen in [Modellanleitung](LOCAL_AI.de.md), [Hybridanleitung](HYBRID_SIGNING.de.md) und [internem Audit](SECURITY_AUDIT.md).
