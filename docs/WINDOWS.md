# Passphrase Memorizer 1.0.1 for Windows

The WPF port preserves the v1.0.1 features and visual layout: English/German, BIP39/EFF word lists, 1–128 words, five literary styles, exact bold blue `[word]` markers, ordered repeated words, temporary ten-minute reveal, concealment on deactivation, clear/cancel/quit cleanup and preferences limited to language, dimensions and model path.

[Download the Windows ZIP and its verification files](https://github.com/michael-feinermann/passphrase-memorizer/releases/tag/v1.0.1). Extract the whole archive to a local NTFS folder and run `Passphrase Memorizer.exe`, keeping every payload and signature file together. Direct execution includes its runtime and needs no .NET SDK; the repository's per-user installation script requires the documented build prerequisites.

The CUDA package `Passphrase-Memorizer-1.0.1-Windows-CUDA-x64.zip` uses its own static native CUDA worker in a less-privileged AppContainer without network capabilities. Model weights, KV cache and model arithmetic are required on the NVIDIA GPU, with no CPU fallback. The build targets Ada GPUs (compute capability 8.9); the installed Gemma 4 31B was tested on an RTX 4090 with 24 GiB VRAM. It reads GGUF directly without contacting Ollama. Weights are excluded from Git and downloads. The package includes .NET 10 and required CUDA libraries. The older ZIP without `CUDA` is the previous CPU edition.

Before CUDA starts, the app sets and freshly verifies `Prefer No Sysmem Fallback` only for its exact runner executable. Unsupported policy APIs or insufficient free VRAM abort generation. The hidden NVIDIA DRS interfaces are verified on driver 617.42. Tokenization, sampling, UI, small metadata and temporary upload buffers still use RAM; they are distinct from resident model/KV buffers. Windows and the NVIDIA driver remain trusted components.

See the [German Windows instructions](WINDOWS.de.md) for the installed model, build/package/install commands and signature verification. The [GPU security audit](WINDOWS_GPU_SECURITY_AUDIT.md) records current validation; the [original CPU audit](WINDOWS_SECURITY_AUDIT.md) is retained as historical evidence.

Private RSA-4096 and ML-DSA-87 keys are stored only at `A:\Passphrase Memorizer Keys`, separately encrypted with Windows DPAPI CurrentUser. The FAT32 key drive cannot enforce NTFS ACLs. Decryption depends on the original Windows account/profile and DPAPI state; backing up this drive alone is not a portable recovery procedure. The signed release uses independently required RSA-PSS/SHA-512 and ML-DSA-87 plus SHA-256, SHA3-512 and Skein-1024-1024 fingerprints. Public key trust must be established independently before installation. There is no publicly trusted Authenticode signature or root-certificate installation.

Neither mnemonic quality nor word-list membership increases phrase entropy. Wallet checksum validation is not performed. Owned mutable buffers are wiped, but irrevocable erasure of every managed/UI/runtime/OS copy is not guaranteed. This is an internal audit, not an external security certification.
